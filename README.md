# Frontfire

Welcome to Frontfire. Frontfire is the development and build environment created for InfrontJS projects.

It is entirely built upon the great esbuild ecosystem.

## Logic

Required structure of an InfrontJS project is as follows

- src/assets/**/*
- src/app/main.js
- src/app/main.css
- src/index.html

Entrypoint for building is main.js and main.css
